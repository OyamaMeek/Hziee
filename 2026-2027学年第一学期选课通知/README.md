# 2026-2027学年第一学期选课通知

**发布者**：教务处

**发布时间**：2026-06-23

**浏览次数**：27884

2026-2027学年第一学期的选课工作即将开始，相关工作安排通知如下：

## 一、选课时间

1. **第一轮选课**：2026年6月25日 10:00起至2026年7月3日 12:00止。

   其中针对大三、大四学生，在第一轮选课期间的第一个时间段放开必修类课程的退课和选课功能，具体时间详见如下安排；自6月29日 12:00开始，所有年级的必修类课程不能自行退选。为避免选课时出现网络拥堵现象，第一轮选课实行分时选课，具体安排如下：

   **特别提醒：**

   - （1）每天夜里 24:00——早上 8:00 不能退选课，请避开这个时间段。
   - （2）在选课前，请查看本人课表并认真了解培养方案要求，提前做好选课规划，以便尽快完成选课。

   转专业学生退课、选课时间段另行通知，在该时间段内各年级转专业学生（包括之前学期转专业成功的学生）可以退选课，其他非转专业学生不可退选课。

2. **选课系统关闭时间段**：2026年7月3日 12:00起至2026年9月11日 10:00止。选课系统在这一时间段会关闭，请选课的同学错开这一时间段。

3. **选课网址**：http://10.130.4.219/csm/login

   **特别提醒：**

   - 外网访问教务系统需要先登录信工 VPN，再访问以上网址，建议提前收藏网址。
   - 选课前请务必在电脑端下载 Microsoft Edge 或 Google Chrome 浏览器，其他浏览器可能出现不兼容的情况。不建议使用手机端选课。

## 二、选课注意事项

1. 每位学生在选课前必须认真阅读《杭州电子科技大学信息工程学院选课管理办法》和《选课指南》（见附件1和附件2）。

2. 为减少学生选课过程中必修环节的漏选、错选等情况，2026-2027学年第一学期的所有必修类课程已按选课对象进行预置选课，无特殊情况必修类课程不得退改选。英语选修课、体育模块课程、公共选修课在系统选课期间开放退、改选。

3. 25级学生在选英语3时只能二选一。选课路径：网上选课 → 公选课选课 → 英语选修；25级高考语种为日语的同学可以选择日语1或日语3，两者只能二选一。

4. **关于体育课程选课的说明：**

   - （1）本学期25级学生体育模块课程，每位学生限选一门，并且不能重复选择已经选过的课程，否则会导致毕业学分不够而不能正常毕业。
   - （2）第一轮选课中的体育模块课程仅开放给大一大二年级学生选课，大三大四年级的体育模块选课将会在第二轮选课后期开放，届时将会统一通知。
   - （3）24级学生的体育5已经参照必修类课程按选课对象进行预置选课，无特殊情况必修类课程不得退改选。

5. **关于普通本科公共选修课选课的说明：**

   **特别提醒**：所有课程的具体修读要求在各专业培养方案的“教学计划进程表”中均有详细说明。

   - （1）**艺术公选课选课**：2023级-2024级学生，要求在“艺术创作与审美体验”模块修读2学分艺术公选课。（已修读原8门艺术公选课课程清单中课程的，认定为以上“艺术创作与审美体验”模块修读。）
   - （2）**思政选修选课**：
     - ① 2023级-2024级学生（含2021级和2022级延长学年学生），要求获得1学分的“四史”教育学分，需修读《中国共产党党史》，学分计入公共选修课模块。
     - ② 2025级-2026级学生，要求修读1学分“四史”教育课程，即修读《中国共产党党史》。
     - ③ 该课程参照必修课，选课之前系统会将这门课直接导入学生课表。
     - ④ 如有因学籍异动等原因未选该门课程的学生，请注意在选课期间提交退补选申请流程进行补选。
   - （3）从2025级起，通识选修课（公共选修课）总计需修读8学分，要求学生在指定课程中修读2学分的沟通与写作课程，在通识教育模块课中修读6学分。其中“沟通与写作课程”要求在沟通与写作课程模块中选课完成修读；“通识教育模块课”的修读要求根据各专业人才培养需求确定，每个模块中的具体课程清单详见选课系统。（注意：不同专业类别里的修读要求分别都有“艺术创作与审美体验”模块修读2学分）。

6. **关于《创新创业教育实践》课程的选课说明：**

   自2026-2027学年起，《创新创业教育实践》课程由创新创业学院统一组织开设。

   - （1）**2023级-2025级学生**：因各专业培养方案中“创新创业教育实践”（课程代码：P9001011）的修读学期不同，对于之前学期尚未开设该课程的专业，尚未修读或未取得该课程学分的学生，自本学期起至该年级的第六学期（其中2023级可以延长至本学期，即该年级的第7学期），从“创新创业教育实践课程”模块中自主选择一门课程完成修读，修读合格后计入“创新创业教育实践”学分（1学分）。
   - （2）**2026级学生**：培养方案中有“创新创业教育实践”（课程代码P9001011）的学生，要求学生在该年级的第2-6学期从“创新创业教育实践课程”模块中自主选择一门完成修读，修读合格后计入“创新创业教育实践”学分（1学分）。
   - （3）**注意**：已修读过原“创新创业教育实践”课程（课程代码P9001011）并取得学分的学生无需重复修读。如有因学籍异动等原因未选该门课程或未获得学分的学生，请注意及时在“创新创业教育实践课程”模块中选课。
   - （4）该模块课程在选课系统的公选课模块进行选课，选择“创新创业教育实践课程”即可看到当学期的课程清单。
   - （5）关于《创新创业教育实践》课程选课的具体要求详见创新创业学院发布的通知。

7. 选课全时段内都能进行重修选课，学生点击“重修选课”进行选课。但在第一轮选课时间段内，受选课年级的限制。**注：非重修课程，一律不得在此界面中选课，否则成绩单上会显示重修标记。** 重修大一新生课程，需等到第二轮选课期间才能选课。

8. 所有必修类课程在选课期间若有特殊原因需要退改选，都需要提交审批流进行申请，申请路径：PC - 选课申请 - 退补选课申请，或者钉钉工作台 - 智慧教务 - 选课管理 - 退补选课申请。请务必在选课期间内完成选课，逾期不予办理退、补选课。

9. 禁止学生使用“选课器”选课，一经发现，退选所有已选课程。因“选课器”选课所造成的错选、漏选、不能退选等后果自负。

10. 结业返校修读的学生在第二轮选课结束前需完成选课，以保障顺利修读课程。

11. 学生在查询课表时，由于系统刷新延迟，可能存在课表内课程显示不完全的情况，请学生以官网已选课程中显示的课程为准。选课结束后3天内（2026年9月25日-9月27日）所有学生都需要在此期间进入选课系统认真核查已选课程和个人课表，如有问题及时反馈到各自所在学院教学秘书处，由学院教学办汇总至排选课办公室处理。

12. **特别提醒：**

    - （1）学生必须按已选课表上课，无故缺课将会导致学期末考试不合格。
    - （2）系统选课和钉钉退补选申请流程完成后，都需要学生及时查看课表确认。
    - （3）学生课表以选课系统网页端查询的为准，其他渠道查到的课表不予认可。

13. 在选课的过程中遇到问题请及时与所在学院教学秘书处联系，之后由学院教学秘书处汇总后报至选排课办公室。
