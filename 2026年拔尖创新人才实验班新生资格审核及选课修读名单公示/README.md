# 2026年拔尖创新人才实验班新生资格审核及选课修读名单公示

**发布者：** 教务处  
**发布时间：** 2026-09-14  

按照《杭州电子科技大学信息工程学院2026年拔尖创新人才实验班新生选拔实施细则》的规定，杭州电子科技大学信息工程学院拔尖创新人才实验班2026年秋季学期选课名额为理工实验班90人，经管实验班50人。2026年拔尖创新人才实验班新生选拔理工实验班通过资格审核424人，经管实验班通过资格审核100人。经审核、测算，现将资格审核通过及选课修读名单公示如下：附件1和附件2。

入围新生如有意放弃2026级拔尖创新人才实验班选课修读资格，请于 **2026年9月15日下午4点前** 将附件3《2026级拔尖创新人才实验班退选申请表》填写后，发送至教务处邮箱：`jwc@hziee.edu.cn`。空缺的选课资格将按照附件1/2中的排名顺序顺延。请各位同学保持电话畅通。

未入围新生可以在 **9月15日早上8点 - 9月16日晚12点** 期间，进行计算机科学与技术（成电联合培养）和电子信息工程专业（成电联合培养）第二轮报名。

公示期为 **2026年9月14日至9月16日**。如有异议，请于公示期内将反馈发送至邮箱：`jwc@hziee.edu.cn`。
