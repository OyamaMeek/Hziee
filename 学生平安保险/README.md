【关于学生商业补充医疗保险（学生平安保险）通知】
【1】学生平安保险作为大学生医保的补充保险，能积极预防、妥善处理在校学生伤害事故。参保公司是由杭电本部统一招标的保险公司。保费每年50元，普本新生四年200元，一次性缴纳。具体政策、报销方式见2026学生平安保险手册pdf文件。
【2】原则上每位学生尽量均需参保学评险。如果确实有学生参加了其他相似类型的保险或其他原因坚决不参加的，请自行打印不参保承诺书并按要求签署，并在表格签名处写上不参保，9月13日班会时由班级临时负责人收齐交给辅导员。
【3】缴费方式：各位班级临时负责人收齐好各班的参保费用（支付宝），参保学生在投保名单纸质版签字，不参保签名处写明不参保。由班长汇总后纸质版和费用一起预计于9月14日（周一）提交，具体时间另行通知，保险公司联系人：戴天
【4】特别提醒：本保险为自愿参保，但是为了以防万一产生意外事故，学平险可以减轻很多费用负担。
